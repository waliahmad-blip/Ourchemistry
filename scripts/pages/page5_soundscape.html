04. Zero-Asset Procedural Web Audio Soundscape

High-fidelity mobile experiences are frequently compromised by downloading large MP3/WAV assets that introduce network latency, memory bloat, and hydration glitches. lib/audio/soundscape.js introduces a purely mathematical procedural synthesis engine with zero asset downloads.

Cardiac Pulse Synthesis Architecture

function playCardiacPulse(audioCtx, bpm = 68) { // Primary ventricle (Lub) const osc1 = audioCtx.createOscillator(); osc1.frequency.setValueAtTime(75, now); osc1.frequency.exponentialRampToValueAtTime(36, now + 0.12); gain1.gain.setValueAtTime(0.24, now); gain1.gain.exponentialRampToValueAtTime(0.001, now + 0.18); // Secondary ventricle (Dub) - Delayed 85ms const osc2 = audioCtx.createOscillator(); osc2.frequency.setValueAtTime(62, now + 0.085); osc2.frequency.exponentialRampToValueAtTime(32, now + 0.22); gain2.gain.setValueAtTime(0.18, now + 0.085); gain2.gain.exponentialRampToValueAtTime(0.001, now + 0.32); }

Hydration-Safe Autoplay Compliance

Browsers enforce strict audio autoplay security policies prohibiting audio playback before explicit user interaction. The Soundscape engine utilizes a lazy singleton SoundscapeEngine that monitors first gestures (drag, tap, keypress) to transition the AudioContext from suspended to running smoothly without runtime warnings.
