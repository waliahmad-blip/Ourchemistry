Cosine Similarity Acoustic Matching

Vector proximity between candidates' Voice DNA embeddings is computed via Cosine Similarity:

Cosine Similarity = [ A • B ] / [ ||A|| * ||B|| ] = [ ∑_{i=1}^{64} A_i * B_i ] / [ sqrt(∑ A_i^2) * sqrt(∑ B_i^2) ] Matches with similarity ≥ 0.82 display high vocal harmonic affinity.

Viral Waitlist Referral Loop

Atomic Referral Logic
Users receive a unique OU-XXXX code upon registration. Incoming traffic with ?ref=CODE automatically awards +500 position rank leaps to the referrer, driving organic referral loops while auto-assigning chemical element affinities (Aqua, Ignis, Terra, Ventus).
Resilient Persistence Architecture
The waitlist endpoint (/api/waitlist) features dual persistence: when DATABASE_URL is connected, it commits to PostgreSQL; in serverless/offline environments, it falls back to atomic write-locked JSON files without throwing 500 errors.
