02. High-Level Topology & Edge Stack

The application architecture follows a distributed, zero-trust edge topology. Client-side digital signal processing (DSP) performs biometric feature extraction on the user's device, while edge serverless handlers enforce strict cryptographic guardrails, state-machine progression, and vector storage.
