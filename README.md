1. **Zero Raw Audio Storage**: Audio is processed strictly in-browser via Web Audio. Only mathematical 64-D vectors leave client memory.
2. **Cryptographic Sealing**: All Astraea responses are signed with SHA-256 hashes verifying that no tampered or vendor-leaked content is served.
